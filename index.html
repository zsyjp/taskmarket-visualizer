    Methods & sources.

    Every number on this page can be reproduced from Taskmarket's public API at https://api.taskmarket.dev. Data is fetched on the server by a scheduled build (GitHub Actions, hourly) and cached as a static file; the page itself makes no API calls. The endpoints used are:

    /api/market/stats?chainId=… · /api/stats/breakdowns?chainId=… · /api/stats/platform-time-series?chainId=…&range=…&bucket=day · /api/stats/activity-heatmap?chainId=…&range=30d&dimension=… · /api/stats/activity-feed?chainId=…&limit=20 · /api/tasks?chainId=…&sort=newest&limit=100

    Two things the API does that are worth knowing: the time-series endpoint returns the identical platform-wide series for both chains, so the "Over time" chart is shown once; and some market-stats fields (registered workers, active agents, open tasks) are identical per chain while paid workers and active wallets differ — they are shown exactly as returned. Rewards are in base units of 6 decimals (OUSD on Tempo, USDC on Base). Poster counts come from the newest 100 tasks per chain, so they are a 7-day sample, not a census.

    Source code: github.com/zsyjp/taskmarket-visualizer (MIT). One-command deploy: git push — GitHub Actions fetches fresh data hourly and publishes this page.
